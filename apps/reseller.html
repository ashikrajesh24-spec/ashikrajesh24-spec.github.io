Reseller API

A REST API that lets resellers pull the product catalogue into their own systems, with pricing and access controlled per key.

  • Products, categories and brands endpoints with pagination and CORS
  • Reseller pricelist plus a global or per-category margin
  • Allowed categories, hide prices, extra fields
  • Every call logged with response time
  • Portal page with keys and a downloadable manual
